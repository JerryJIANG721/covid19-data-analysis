# COVID-19 Data Analysis

## Overview
This project explores a global COVID-19 dataset using Python.  
The goal is to practice **data cleaning, aggregation, and visualization** with **Pandas** and **Matplotlib**.  
The analysis focuses on infection and recovery trends across different countries.

## Methods
- Cleaned and preprocessed the dataset (missing values, formatting dates).
- Aggregated data by country and by time period.
- Computed key indicators such as infection rate, recovery rate, and death rate.
- Visualized trends with line plots and comparisons between countries.

## Tools
- Python 3  
- Pandas  
- Matplotlib

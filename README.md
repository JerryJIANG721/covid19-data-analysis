# COVID-19 Data Analysis and Forecasting

## Overview

This project analyzes a global COVID-19 dataset using Python.
It focuses on **data cleaning, aggregation, visualization, and forecasting** to understand both historical and future trends of the pandemic.
The analysis covers infection, recovery, and death patterns across different countries, with an emphasis on **short-term prediction of case trends**.

## Methods

* Performed data cleaning and preprocessing (handling missing values, formatting dates).
* Aggregated data by country and time period.
* Computed key indicators such as infection rate, recovery rate, and death rate.
* Visualized trends using line plots and cross-country comparisons.
* Built **time-series and machine learning models** to forecast future COVID-19 cases and analyze projected trends.
